# OnlineShop-Backend
پروژه بک اند یک سایت فروشگاهیه با pythom, fastapi, sqlalchemy توسعه داده شده.
برای ارسال کد های otp به شماره موبایل از سرویس کاوه نگار (https://kavenegar.com/) استفاده شده. 
پروژه همچنان در حال توسعه هستش و به مرحله عملیاتی نرسیده و بخش هایی مثل اتصال به درگاه پرداخت و ذخیره سازی تصاویر محصولات نیاز به انجام تست و اصلاحات دارن.
تو مراحل بعدی توضیحات کامل تری درباره پروژه داده میشه.
